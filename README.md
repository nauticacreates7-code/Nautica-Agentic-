This project is an **Agentic Research Paper Plagiarism Checker** built for reviewing potential overlap between a submitted paper and scholarly sources. Users upload a PDF, and the FastAPI backend extracts its text, splits the paper into passages, searches arXiv and Semantic Scholar for candidate sources, and compares each passage with available source abstracts using sentence embeddings and word-level overlap. The report presents an overall similarity score, passage-level scores, source links, evidence such as shared word sequences and sentence alignment, citation indicators, and document coverage. An explanation chatbot can answer questions about the report using its stored evidence and display the tools it used. The frontend is a single static HTML page built with vanilla JavaScript and Tailwind CSS via CDN; the backend is written in Python with FastAPI. To run locally, install the packages listed in `requirements.txt`, set `OPENROUTER_API_KEY` as an environment variable if you want OpenRouter-powered explanations, then start the server with `python -m uvicorn main:app --reload` from the project folder and open `http://127.0.0.1:8000/`. Similarity results are intended as indicators for human review, not proof of plagiarism; comparisons are limited to the sources and abstracts the search APIs return.
